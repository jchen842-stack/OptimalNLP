# Reproducing these results from a clean clone

Verified end-to-end on macOS (darwin 25.5.0), CPU only. No GPU is used or required.

## 0. Inputs that are NOT in this repo

| input | size | where it comes from |
|---|---|---|
| **upstream method** — `compositional/`, `utils/` | — | `git clone https://github.com/aiea-lab/optimal-compositional-explanations` then `git checkout 70805299fc0758951a650197bffcc792d0ccca20` (the SHA in `UPSTREAM`), plus `patches/0001-frontier-beam-fallback.patch` |
| **NLI codebase** — `models.py`, `data/snli.py` | — | `git clone https://github.com/jayelm/compexp` (the `nli/code` subtree of Mu & Andreas 2020) |
| **annotations** — `snli_1.0_dev.feats` | ~14 MB | ships with the NLI codebase at `nli/data/analysis/` |
| **SNLI corpus** — `snli_1.0_train.jsonl`, `_dev.jsonl` | ~100 MB | https://nlp.stanford.edu/projects/snli/ → `nli/code/data/snli_1.0/` |
| **trained checkpoint** — `models/bowman_snli_best.pth` | 54 MB | gitignored. Retrain per `models/README.md`, or obtain the file |
| **activations** — `results/*.npz` | 0.1–2 MB each | gitignored; regenerated by step 3 below |

Environment variables consumed by the scripts:

```sh
export OPTIMALCE_UPSTREAM=$HOME/projects/optimalce                       # patched upstream
export NLI_CODE=$HOME/projects/neuron-explanations-nli/nli/code          # NLI codebase
```

Python deps: `numpy`, `scipy`, `torch`, `nltk` (whatever the NLI codebase needs). Verified
against numpy 1.23.5. `detectron2` and `cityscapesscripts` are **not** needed — they are
stubbed at import (see `VERIFICATION.md` check 6).

## 1. Apply the upstream patch

```sh
cd $OPTIMALCE_UPSTREAM
git checkout 70805299fc0758951a650197bffcc792d0ccca20
git apply $REPO/patches/0001-frontier-beam-fallback.patch
```

This adds `MAX_FRONTIER_SIZE` (default `None`) and two call sites. With `None` it is a
verified no-op — see `VERIFICATION.md` check 3.

## 2. Concept masks and the unique-element measurement

```sh
python src/unique_elements.py            # -> results/unique_elements.csv
```

Expected: 24,199 tokens from 2,000 sentences; 1,168 of 3,109 (category,value) pairs clear
`min_support=5`; unique-element fraction 0.139; mean overlap 3.189.

## 3. Activations (needs the checkpoint)

```sh
python src/real_activations.py --max_sents 2000 --untrained \
    --alphas 0.5 0.2 0.1 0.05 0.005 --out results/acts2k_untrained.npz

python src/real_activations.py --max_sents 2000 --ckpt models/bowman_snli_best.pth \
    --alphas 0.5 0.2 0.1 0.05 0.005 --out results/acts2k_trained.npz
```

Expected for the trained arm: `OOV 2137/24199 (8.8%)`, `states (24199, 512)`, and mean
densities 0.4977 / 0.1965 / 0.0938 / 0.0467 / 0.0049.

Each writes 5 files, `results/acts2k_{arm}_a{alpha}.npz`. One forward pass serves all
alphas — the encoder does not depend on alpha, only the threshold does.

## 4. One alpha-sweep row (Phase A, beam)

Trained arm, alpha = 0.1. Takes about 5 seconds.

```sh
python src/real_token_search.py --arms all --K 15 --lengths 4 --min_support 5 \
    --max_sents 2000 --cap 200000 --time_budget 300 --seed 0 \
    --neuron real --beam_list 200 --acts results/acts2k_trained_a0.1.npz \
    --units 5 --dmin 0 --dmax 1 --min_fire 200 \
    --out results/alpha_row_trained_a0.1.csv
```

Expected: units 88, 92, 396, 413, 510; no timeouts; mean lift ≈ 2.42.

Report over a directory of such CSVs:

```sh
python src/alpha_sweep_report.py --glob 'results/alpha_row_*.csv' \
    --out results/alpha_sweep_K15.csv
```

## 5. The length-3 grid

Exact search at length 3 across K, all 20 runs in well under a minute:

```sh
for K in 15 30 50; do
  python src/real_token_search.py --arms all --K $K --lengths 3 --min_support 5 \
      --max_sents 2000 --cap 200000 --time_budget 1500 --seed 0 \
      --neuron real --beam_list none --acts results/acts2k_trained_a0.1.npz \
      --unit_ids 88 92 396 413 510 --dmin 0 --dmax 1 --min_fire 200 \
      --out results/L3_all_K$K.csv
done

python src/real_token_search.py --arms lemma --K 50 --lengths 3 --min_support 5 \
    --max_sents 2000 --cap 200000 --time_budget 1500 --seed 0 \
    --neuron real --beam_list none --acts results/acts2k_trained_a0.1.npz \
    --unit_ids 88 92 396 413 510 --dmin 0 --dmax 1 --min_fire 200 \
    --out results/L3_lemma_K50.csv
```

Expected wall times: K=15 0.4–1.9s, K=30 2.0–4.5s, K=50 4.7–8.5s, lemma K=50 0.0–0.3s.
No timeouts at any K.

For the matched-length band comparison, run the same grid at `--beam_list none` and
`--beam_list 200` into two directories and join:

```sh
python src/phaseB_report.py --beam_glob 'DIR_beam/*.csv' \
    --exact_glob 'DIR_exact/*.csv' --out results/beam_vs_exact_L3_K15.csv
```

Expected: 27 pairs, ratio-of-averages +0.96% over all pairs and +5.05% restricted to pairs
whose solutions differ, with 20 of 27 agreeing exactly.

## 6. Phase B at length 4 (slow)

Same as step 5 with `--lengths 4` and `--time_budget 1500`. **This is the expensive one:**
27 runs, 23–1500s each, roughly 4 hours total, and 4 runs hit the cap. The time budget is
*soft* — it is checked once per 256 heap pushes, and one run overshot to 2085s against a
1500s cap.

## 6b. Verified from a clean clone — where it breaks

This document was tested by cloning the repo into an empty directory and following it. The
results, so a reader knows what to expect:

| step | outcome from a clean clone |
|---|---|
| 2 — `unique_elements.py` | **works.** Needs only `snli_1.0_dev.feats` |
| 3 — `real_activations.py --untrained` | **works.** No checkpoint needed; prints `[align] 24199 rows; token ORDER verified on 50 sampled indices` |
| 4 / 5 — search against the **untrained** arm | **works**, once step 3 has run |
| 3 / 4 / 5 — anything on the **trained** arm | **BREAKS.** Needs `models/bowman_snli_best.pth`, which is gitignored |
| 7 — `verify/check_masks.py` | **works** |
| 7 — `check_alignment.py`, `check_binarise.py`, `check_model.py` | **partially break.** They want the checkpoint. `check_alignment.py` now skips the trained arm with a message; the other two require it |
| 7 — `check_iou.py`, `check_stubs.py`, `check_stub_calltrace.py`, oracle | need `results/*.npz` from step 3 |

**The whole untrained path reproduces from a clean clone with no extra artifacts beyond the
`.feats` file.** Everything involving the trained arm requires either the 54 MB checkpoint or
a retrain (`models/README.md`). Running a search before step 3 now fails with an explanatory
message naming the command to run, rather than a bare `FileNotFoundError`.

## 7. Re-run the audit

One command runs everything and prints a PASS / FAIL / CANNOT VERIFY table, exiting nonzero
if anything failed:

```sh
./verify/run_all.sh
```

**No manual setup is needed for the patch no-op check (check 3).** It compares our patched
upstream against a clean copy at the pinned SHA, and clones that copy itself into
`.upstream-clean/` (gitignored) on first run — the upstream repo is public and needs no
credentials. It verifies the clone is at the SHA in `UPSTREAM` and fails rather than passing
if it is not. With no network it prints the exact clone command instead of skipping silently.

It needs no gitignored inputs either: it uses the documented neuron when
`results/acts2k_trained_a0.2.npz` is present and the proxy neuron otherwise, so **from a bare
clone with only the `.feats` corpus it runs and passes** (4/10 PASS, 6 CANNOT VERIFY, exit 0).

Individual checks, if you want them one at a time:

```sh
python verify/check_alignment.py       python verify/check_masks.py
python verify/check_padding.py         python verify/check_stubs.py
python verify/check_iou.py             python verify/check_stub_calltrace.py
python verify/check_binarise.py        python verify/check_model.py
ORACLE_LENGTH=3 python tests/test_bruteforce_oracle.py
# check 3 compares two trees; run it via run_all.sh, or set OPTIMALCE_UPSTREAM by hand
```

## Unrecorded seeds — nothing papered over

| seed | status |
|---|---|
| **training seed** for `bowman_snli_best.pth` | **NOT RECORDED.** `--seed` defaults to 0 and is applied via `torch.manual_seed`, but the run demonstrably did *not* use all defaults (it needed `--max_data 0`), so the default cannot be assumed. A retrain that does not hit 0.7934 means the seed differed. |
| untrained-encoder weights | `--seed 0` default, applied via `torch.manual_seed` before `TextEncoder` construction. Reproducible, but **torch RNG behaviour is version-dependent**; a different torch version may give different random weights and therefore different untrained-arm numbers. The torch version used was not recorded. |
| unit selection | `np.random.default_rng(seed + 999)`, seed 0. Reproducible — **but only for a fixed eligible set.** Any change to `--dmin/--dmax/--min_fire` changes which units are drawn. Use `--unit_ids` to pin them. |
| proxy neuron noise | `np.random.default_rng(seed + 999)`, seed 0, `--noise 0.05`. Reproducible. |
| permutation test | `random.Random(0)` in `phaseB_report.py`. Reproducible. |

## Known non-determinism

- Wall times in every CSV are machine-specific and will not reproduce.
- Timeout rows depend on wall clock, so **which** runs time out is machine-dependent. On a
  faster machine some of the 4 length-4 timeouts may complete, changing n from 23.
- Float round-off in the LSTM forward pass is ~1e-8 (`VERIFICATION.md` check 2); IoU values
  reproduce exactly on the same machine but may differ in the last bits across BLAS builds.
